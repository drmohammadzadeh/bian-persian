# واژه‌نامه تخصصی و اصطلاح‌نامه استاندارد BIAN به فارسی
# (BIAN-Iran Banking Lexicon & Terminology)

این سند مرجع رسمی اصطلاحات، تعاریف و ترجمه‌های یکدست استاندارد **BIAN (Banking Industry Architecture Network)** برای صنعت بانکداری، پرداخت و فناوری اطلاعات مالی ایران است.

---

## ۱. ارکان و مفاهیم بنیادین معماری BIAN (Core Architectural Concepts)

| اصطلاح انگلیسی | معادل استاندارد فارسی | تعریف و کاربرد در معماری |
| :--- | :--- | :--- |
| **Service Domain (SD)** | **دامنه سرویس** | کوچک‌ترین واحد مستقل و دارای مرز مشخص در معماری BIAN که یک توانمندی کسب‌وکار (Business Capability) یکتا را مدیریت می‌کند. |
| **Control Record (CR)** | **رکورد کنترلی / دارایی محوری** | موجودیت و دارایی اطلاعاتی اصلی که چرخه عمر آن توسط دامنه سرویس مدیریت می‌شود (مانند توافق‌نامه حساب یا پرونده تسهیلاتی). |
| **Behavior Qualifier (BQ)** | **شناسه رفتاری / جزء عملیاتی** | بخش‌های فرعی و عملکردهای تخصصی ذیل یک رکورد کنترلی (مانند کارمزد، مسدودی، سود یا صدور دسته‌چک). |
| **Functional Pattern** | **الگوی عملکردی** | الگوی رفتاری کلان BIAN (مانند `Manage`, `Fulfill`, `Operate`, `Agree`, `Authorize`) که شیوه تعامل دامنه را تعیین می‌کند. |
| **Business Scenario** | **سناریوی کسب‌وکار** | توالی تعاملات بین دامنه‌های سرویس مختلف برای اجرای یک فرآیند بانکی کامل (مانند افتتاح حساب یا اعطای وام). |
| **Service Operation** | **عملیات سرویس** | نقطه اتصال و API مشخص برای فراخوانی یک سرویس معین در یک دامنه. |
| **Semantic API** | **رابط برنامه‌نویسی معنایی** | تعریف مستقل از فناوری API بر اساس مدل داده و واژگان استاندارد BIAN. |

## ۲. افعال و ترم‌های عملیاتی استاندارد (Action Terms)

استاندارد BIAN از مجموعه‌ای ثابت از افعال عملیاتی (Action Terms) استفاده می‌کند. در نسخه بومی ایران، این افعال به صورت زیر معادل‌سازی شده‌اند:

| ترم عملیاتی (Action Term) | پیشوند BIAN | معادل فارسی | شرح عملیات در سیستم بانکی |
| :--- | :--- | :--- | :--- |
| **Initiate** | `In` (مانند `InCR`, `InBQ`) | **افتتاح / آغاز** | آغاز یک موجودیت، افتتاح حساب، یا ثبت درخواست اولیه پرونده. |
| **Execute** | `Ex` | **اجرا / عملیات** | اجرای یک تراکنش مالی یا دستور اداری (مانند واریز، برداشت یا مسدودی). |
| **Update** | `Up` | **بروزرسانی** | تغییر مشخصات، شرایط یا فیلدهای اطلاعاتی یک رکورد موجود. |
| **Record** | `Rc` | **ثبت رویداد** | ثبت لاگ، سابقه تراکنش یا رویداد حسابرسی بدون تغییر وضعیت مستقیم. |
| **Retrieve** | `Re` | **استعلام / دریافت** | خواندن اطلاعات، استعلام مانده یا گزارش‌گیری از گردش حساب و وضعیت. |
| **Request** | `Rq` | **درخواست** | درخواست انجام یک خدمت یا فرآیند وابسته (مانند درخواست صدور دسته‌چک). |
| **Evaluate** | `Ev` | **ارزیابی / اعتبارسنجی** | سنجش شایستگی، اعتبارسنجی مشتری یا ارزیابی ریسک. |
| **Authorize** | `Au` | **مجوزدهی / تایید** | صدور مجوز تراکنش، احراز هویت دارنده کارت و کنترل سقف‌های مالی. |
| **Notify** | `No` | **اطلاع‌رسانی / اعلان** | ارسال رویداد، پیامک یا اعلان وب‌هوک به مشتری یا سامانه‌های دیگر. |

## ۳. نگاشت دامنه‌های مرجع BIAN با مفاهیم بانکداری ایران

| نام دامنه BIAN | نام فارسی دامنه | سامانه / مفهوم متناظر در ایران |
| :--- | :--- | :--- |
| **Current Account** | **حساب قرض‌الحسنه جاری** | مدیریت حساب جاری، دسته چک صیادی، چکاد، و مسدودی‌های قضایی (سامانه سیاح). |
| **Savings Account** | **حساب قرض‌الحسنه پس‌انداز** | حساب‌های پس‌انداز و قرعه‌کشی‌های قرض‌الحسنه. |
| **Term Deposit** | **سپرده سرمایه‌گذاری مدت‌دار** | سپرده‌های کوتاه‌مدت و بلندمدت با پرداخت سود علی‌الحساب ماهانه. |
| **Consumer Loan** | **تسهیلات خرد** | تسهیلات انفرادی در قالب عقود اسلامی (مرابحه، جعاله، قرض‌الحسنه). |
| **Corporate Loan** | **تسهیلات شرکتی و کلان** | تسهیلات کلان حقوقی در قالب مشارکت مدنی، مضاربه، سلف و استصناع. |
| **Payment Order Initiation** | **دستور پرداخت** | هدایت پرداخت‌ها به سامانه‌های پایا، ساتنا، پل و انتقال داخلی. |
| **Card Authorization** | **مجوزدهی کارت** | سوئیچ صادرکنندگی (Issuer Switch)، رمز پویا، CVV2 و اتصال به شتاب و شاپرک. |
| **Card Transaction Switch** | **سوئیچ تراکنش‌های کارت** | سوئیچ پذیرندگی و هدایت تراکنش‌های خودپرداز و کارتخوان (شتاب). |
| **Merchant Acquiring Facility** | **پذیرندگی کارت و پایانه‌ها** | مدیریت پذیرندگان شاپرک، درگاه اینترنتی (IPG) و دستگاه پوز (POS). |
| **Party Lifecycle Management** | **مدیریت چرخه عمر مشتری** | اطلاعات مشتری (CIF)، کد ملی و ثبت در سامانه متمرکز نهاب (شناسه شهاب). |
| **Party Authentication** | **احراز هویت مشتری** | اعتبارسنجی هویت، تطبیق شاهکار (کدملی و موبایل) و امضای دیجیتال. |
| **Collateral Asset Administration** | **مدیریت وثایق و تضامین** | توثیق ملک، سهام، سفته الکترونیک و مسدودی سپرده طبق آیین‌نامه بانک مرکزی. |
| **Credit Facility** | **خطوط و حد اعتباری** | تخصیص حد اعتباری، کارت اعتباری مرابحه و اعتبار در حساب جاری. |
| **Financial Accounting** | **حسابداری مالی و کل** | دفترکل (General Ledger)، سندداری دوبل و گزارش‌های مالی اسناد حسابداری. |

## ۴. واژگان داده‌ای و متغیرهای مالی بومی (Data Elements)

* **کد ملی (`NationalId`):** شناسه هویتی یکتای ۱۰ رقمی اشخاص حقیقی صادره از سازمان ثبت احوال کشور.
* **شناسه ملی حقوقی (`LegalEntityId`):** شناسه ۱۱ رقمی یکتای شرکت‌ها و نهادهای حقوقی صادره از ثبت شرکت‌ها.
* **شناسه شهاب (`ShahabId`):** شناسه هویت الکترونیکی بانکی (۱۶ رقمی) تولیدشده توسط سامانه نهاب بانک مرکزی ایران.
* **شماره شبا (`IbanNumber`):** شناسه ۲۶ کاراکتری حساب بانکی ایران (`IR...`) بر اساس استاندارد ISO 13616.
* **شناسه صیاد (`SayadChequeId`):** شناسه یکتای ۱۶ رقمی صیادی چک برای استعلام اعتبار صادرکننده و ثبت برخط چک.
* **تاریخ جلالی (`JalaliDate`):** تقویم خورشیدی هجری شمسی مورد استفاده رسمی در کشور.
* **وجه التزام (`LatePaymentPenalty`):** خسارت تأخیر تأدیه دین طبق مصوبات شورای فقهی و بانک مرکزی به عنوان جریمه تأخیر.
